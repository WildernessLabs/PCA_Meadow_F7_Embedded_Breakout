# PCA_Meadow_F7_Embedded_Breakout
Printed Circuit Assembly (PCA) design of the breakout dev board for the Meadow F7 Embedded SMT Module

Designed using Kicad 5.1.6 

Import the fp-lib-table (found in the Circuit_Part_Libraries depot) to make sure your libraries work
WP_LIB is where your "Circuit_Part_Libraries\Libraried_Kicad" is located. 

Gerbers, drills and stack up are located in PCB_FAB folder
BOM is located in Assembly Folder
Pick and Place files are located in the Assembly folder
